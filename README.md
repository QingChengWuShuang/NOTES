## NOTES_FOR_NWPU

本Github项目为 **西北工业大学某某某学院2024级的MirrorMoon** 同学维护的项目。



该项目旨在让大家用较短的时间 **顺利通过考试** 或者是 **取得理想成绩** 。



## 一些声明：

（1）由于一些不可避免因素（如 $MirrorMoon$ 同学有时比较粗心、过于摆烂等原因），笔记可能存在一些疏忽和漏洞，欢迎大家指正。反馈通道：欢迎添加 $MirrorMoon$ 同学的QQ进行反馈：2510063948，在此乐意与志同道合的朋友们共同交流知识，“谈笑有鸿儒”。

（2）一些文件过大，将使用网盘上传到频道，如有需要可以在《启翔湖畔-西北工业大学》搜索“宿命光学”，每次开源的笔记大多数会附上云盘链接，如有需要原件亦可以添加 $MirrorMoon$ 同学的QQ。

（3）请关注频道”宿命光学“谢谢喵！

（4）本笔记的“大学物理”部分采用了东北大学-大学物理课程的部分ppt截图，在此特别鸣谢东北大学。

（5）本笔记的“概率论与数理统计“部分采用了“一高数”的《概率论与数理统计课程》中部分ppt截屏，在此特别鸣谢“一高数”老师的分享，开源可贵、知识无价、赛博孔子、通俗易懂、逻辑清晰。

（6）本笔记的“数电”部分采用了“灿出品”老师的《数字电子技术》中部分ppt截屏，在此特别鸣谢“灿出品”老师的分享，知识付费、精品内容、深入浅出、通俗易懂、理解深刻。
